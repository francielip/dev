Variáveis, tipos de dados e entrada e saída de dados

Variável: espaco da memoria que guardo uma informacao que pode mudar ao longo do tempo. Em python, não precisamos declarar o tipo da variável, pois o Python é uma linguagem de tipagem dinâmica. Exemplo: nome = "Francieli" (aqui, a variável nome é do tipo string, mas não precisamos declarar isso explicitamente). Variáveis podem ser usadas para armazenar diferentes tipos de dados, como números, textos,

Constante: espaco da memoria que guardo uma informacao que nao vai mudar ao longo do tempo. Em Python, usamos letras maiúsculas para indicar constantes. Exemplo: PI = 3.14 (aqui, PI é uma constante que representa o valor de pi). Constantes são úteis para valores que não devem ser alterados, como taxas de juros, limites máximos, etc.

Tipos de dados: é o tipo de dado que estou armazendando na variavel ou constante. Exemplo: inteiro, numeral, texto, boleano. Em Python, temos os seguintes tipos de dados básicos: - Inteiros (int): números inteiros, como 1, 2, 3. - Flutuantes (float): números com ponto decimal, como 3.14, 2.5. - Strings (str): sequências de caracteres, como "Olá", "Python". - Booleanos (bool): valores lógicos, True ou False. Podemos converter entre tipos de dados usando funções como int(), float(), str(). Python é dinamicamente tipada, o que significa que não precisamos declarar o tipo de uma variável antes de usá-la. O Python infere o tipo automaticamente com base no valor atribuído.

Entrada e Saída de dados: Entrada: é quando o usuario informa algo ao programa. Exemplo: nome, idade, salario. Saída: é quando o programa informa algo ao usuario. Exemplo: mensagem de boas-vindas, resultado de um calculo, informacao de erro. Em Python, usamos a função input() para entrada de dados e print() para saída de dados. Exemplo de entrada de dados: nome = input("Digite seu nome: ") Exemplo de saída de dados: print("Olá, " + nome + "! Bem-vindo ao programa.")

Expressões

Expressões - combinações de variáveis, constantes, operadores e funções que resultam em um valor. Exemplo: 2 + 3 * 4 (aqui, a expressão resulta em 14).

Expressões > Aritiméticas: matemáticas (soma, subtração, multiplicação...)

Quem define se o número é par ou impar é o resto da divisão.

Expressões > Lógicas

Expressões Lógicas > Operadores: simbolos que iremos utilizar ao longo do codigo para operadores matematicas (mais, menos, vezes...), de comparacao (igual, maior, diferente...) e de logica (e - ou).

Expressões Lógicas > Operadores > Relacionais: maior, maior que, menor, menor que...

Expressões Lógicas > Operadores > Lógicos: and, or, not.

Estruturas de controle

Estruturas de controle - permitem controlar o fluxo do programa, decidir quais partes do código serão executadas com base em condições.

Sao como perguntas que o computador faz para responder em seguida e tomar decisoes. Ex.: Se idade maior ou igual a 18, voce pode dirigir, senao, voce nao pode dirigir. Computador pode lidar com diferentes cenarios.

Estrutura de seleção/decisão - Simples: usa somente o IF e se não for, irá pular.

Estrutura de seleção/decisão - Composta: usa o IF/ELSE.

Estrutura de seleção/decisão - Encadeada: usa o IF/ELSE e dentro dele outr if/else.

Estrutura de seleção/decisão - Múltipla: usa if - elif - else ou switch/case

Estrutras de repeticao / Laços - FOR/WHILE

Permite q repite o trecho de codigo sob uma condicao (permite fazer os loops). For - while. Repetição com teste no início: primeiro pergunta e depois executa o código. Exemplo: while (condição) { // código a ser repetido }. Repetição com teste no final: executa primeiro o código e depois pergunta. Exemplo: do { // código a ser repetido } while (condição). Repetição com contador ou variável de controle: usa uma variável para contar quantas vezes o código foi execut Ex.: for i in range (4)

Vetores, Matrizes e Registros

Estrutura de dados: é uma forma de organizar e armazenar dados para que possam ser usados de maneira eficiente. Arrays: são coleções de elementos do mesmo tipo, acessados por um índice. Exemplo: lista de números, onde cada número é um elemento do array. Linked lists: são coleções de elementos onde cada elemento aponta para o próximo, formando uma cadeia. Exemplo: lista de tarefas, onde cada tarefa é um elemento da lista. Homogêneas: estrutura de dados onde todos os elementos são do mesmo tipo. Exemplo: array de inteiros, onde todos os elementos são números inteiros. vetor: é uma estrutura de dados que armazena uma coleção de elementos do mesmo tipo, acessados por um índice. Exemplo: lista de nomes, onde cada nome é um elemento do vetor. ex.: numeros = [0] * 5 (Criando um vetor com 5 repetições, iniciando com 0) matriz: é uma estrutura de dados bidimensional, onde os elementos são organizados em linhas e colunas. Exemplo: tabela de notas, onde cada linha representa um aluno e cada coluna representa uma disciplina. ex.: matriz = [[0 for _ in range(3)] for _ in range(3)] (Criando uma matriz 3x3 com zeros) Heterogêneas: estrutura de dados onde os elementos podem ser de tipos diferentes. registros: são estruturas de dados que permitem agrupar diferentes tipos de dados em um único objeto. Exemplo: cadastro de alunos, onde cada aluno tem nome, idade e matrícula. Classes: são estruturas de dados que permitem criar objetos com propriedades e métodos. Exemplo: classe Aluno, onde cada aluno tem nome, idade e matrícula, e pode realizar ações como matricular-se em uma disciplina. Structs: são estruturas de dados que permitem agrupar diferentes tipos de dados em um único objeto, semelhante aos registros. Exemplo: struct Aluno, onde cada aluno tem nome, idade e matrícula.

Funções

Funções: conhecida também como subrotina. É um bloco de código que executa uma tarefa específica e pode ser reutilizado em diferentes partes do programa. Exemplo: função que calcula a média de duas notas. Em Python, definimos uma função usando a palavra-chave def, seguida pelo nome da função e parênteses. Exemplo: def calcular_media(nota1, nota2): return (nota1 + nota2) / 2. Funções podem receber parâmetros (valores de entrada) e retornar valores (resultado da execução). Exemplo de chamada de função: media = calcular_media(7, 8). Um bloco de código independente do programa principal, que pode ser chamado quando necessário. Permite organizar o código em partes menores e mais fáceis de entender. no Python, usamos a palavra-chave def para definir uma função. Exemplo: def minha_funcao(parametro1, parametro2): # código da função. Funções podem receber parâmetros (valores de entrada) e retornar valores (resultado da execução

Fase 1 - Fundamentos de Programação

Lógica de Programação

Permite estruturar o racicionio em comandos. Materializar o raciocinio em logica.

Pseudocodigo - proxima a linguagem humana, para facilitar no inicio do aprendizado. Rascunho escrito em linguagem simples. Ex.: 1. verifique se esta chovendo - 2. se estiver chovendo, pegue o guarda chuva. 3. se nao, saia sem o guarda chuva. Ajuda a planejar e estruturar o codigo antes de executar.

Fluxogramas - forma visual de representar a logica do programa. Ajuda a entender a logica do programa sem entender de linguagem de programacao.

Algoritmos - conjunto de passos que nos ajudam a resolver problemas. Exemplo: manual de montaegm de uma cadeira. Instrucoes para a maquina executar as tarefas e funcionalidades.Outro exemplo, fazer o bolo. Existe uma logica e sequencia para a execucao. E uma receita a nivel de maquina. (eu)

Operadores - simbolos que iremos utilizar ao longo do codigo para operadores matematicas (mais, menos, vezes...), de comparacao (igual, maior, diferente...) e de logica (e - ou).

Condicionais - controla o fluxo do nosso codigo. If - else, switch - case Sao como perguntas que o computador faz para responder em seguida e tomar decisoes. Ex.: Se idade maior ou igual a 18, voce pode dirigir, senao, voce nao pode dirigir. Computador pode lidar com diferentes cenarios.

Estrutra de repeticao - permite q repite o trecho de codigo sob uma condicao (permite fazer os loops) For - while

Metodo dos 5Qs: Ajuda a pensar no algoritmo de forma estruturada e pratica. 1 - O que? O que queremos resolver. Definir o problema ou tarefa que o algoritmo precisa executar. 2- Por que? Porque resolver isso? Qual a motivacao por traz do problema. Ajuda a conectar a logica com o proposito real. 3 - Quando? Quando isso sera utilizado? Organiza o momento que o algoritmo sera ativado. 4 - Onde? Onde sera executado? Onde executar o algoritmo. 5 - Quem? Quem ira executar isso? Importante para planejar as entradas e saidas. Exemplo de media das notas do aluno inseridas pelo professor.

Variáveis, tipos de dados e entrada e saída de dados

Variável: espaco da memoria que guardo uma informacao que pode mudar ao longo do tempo.

Constante: espaco da memoria que guardo uma informacao que nao vai mudar ao longo do tempo.

Tipos de dados: é o tipo de dado que estou armazendando na variavel ou constante. Exemplo: inteiro, numeral, texto, boleano.
